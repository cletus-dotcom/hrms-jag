HRMS — DTR Process to Payroll

LGU Jagna · Quincena workflow for Admin, HR, and Payroll Maker

Download Word (.docx) Download flowchart PDF
Key point: Payroll reads quincena snapshots (work_hours and DtrQuincenaWorktimeSummary) produced by Process Worktime. It does not re-read live punch rows on every pay run when those snapshots exist.

A. Overview (text flow)

Prepare DTR Period → Open Quincena Processing → Upload / fix DTR → Set duty rules (Flexible Worktime, X-Service, OT Auth) → Process Worktime (write snapshots) → Worktime Summary → JO/COS or Plantilla Payroll → Generate payslips

B. Step-by-step process

1. Prepare period

  1. Prepare DTR Period — select year, month, and quincena half (1–15 or 16–end).
  2. Quincena Processing — set or confirm the review window and deadline for the period.

2. Capture attendance

  1. Upload DTR Log — import biometrics or Excel punch file.
  2. System stores punches in daily_time_records (AM in/out, PM in/out).
  3. Resolve punch flags; edit DTR remarks; process DTR justifications.
  4. Apply approved leave, holidays, and special-day remarks that affect payable days.

3. Set duty rules (before Process Worktime)

  1. Flexible Worktime — assign custom schedules (including overnight / weekend duty where applicable).
  2. X-Service Authorization (JO/COS) — authorize extended-service dates; OT is credited to jo_cos_overtime when punches fall within authorized windows (does not add to regular work_hours payroll base).
  3. Overtime Authorization (Plantilla) — authorize OT windows; regeneration may post CTO to leave_ledger. This does not change work_hours / payroll hours.

4. Process Worktime (critical handoff)

  1. Run Process Worktime / Regenerate DTR for the quincena.
  2. System computes per employee per day: gross, late, undertime, and absence minutes.
  3. Writes daily snapshot rows to work_hours.
  4. Writes quincena totals to DtrQuincenaWorktimeSummary.
  5. Applies side effects as configured: VL/SL ledger entries, Plantilla CTO, JO/COS overtime credits.
Important: Re-run Process Worktime after changing Flexible Worktime, X-Service, OT Authorization, or punches for that quincena. Otherwise payroll still uses the old snapshot.

5. Plantilla monthly gate

  1. Monthly DTR Submissions — Plantilla employees review/submit monthly DTR where this gate is configured.

JO/COS typically follow the quincena path without this monthly submission gate.

6. Payroll

  1. Open Worktime Summary — verify quincena snapshots before computing pay.
  2. JO/COS Payroll — paid days from gross minutes ÷ shift length (rounded) × daily rate; deduct late/undertime and other deductions; generate payslips.
  3. Plantilla Payroll — accrued pay less government and other deductions (GSIS, HDMF, PHIC, LBP, etc.); generate payslips.

C. Operator checklist

  1. Prepare DTR Period → open Quincena Processing
  2. Upload DTR → fix flags / remarks / justifications
  3. Set Flexible Worktime, X-Service (JO/COS), and OT Auth (Plantilla) if needed
  4. Run Process Worktime (writes the snapshots payroll uses)
  5. Check Worktime Summary
  6. Run JO/COS or Plantilla payroll → generate payslips

D. Computation summary by employment track

JO/COS

  • Pay base: Gross work minutes ÷ shift length (480 minutes default, or flexi average when on Flexible Worktime) → paid days (rounded) × daily rate.
  • Late / undertime: Deducted separately from gross (not double-counted from net-rendered minutes).
  • X-Service: Authorized dates are excluded from regular worktime and credited to jo_cos_overtime only when punches fall within authorized windows.
  • Snapshot used: work_hours + DtrQuincenaWorktimeSummary for the selected year / month / quincena.

Plantilla

  • Pay base: Accrued from appointment / schedule; plantilla net worktime for snapshot purposes is essentially gross (leave handled via leave_ledger).
  • Leave / CTO: VL/SL deductions and CTO earned are posted on leave_ledger during regeneration where applicable.
  • OT Authorization: Does not change work_hours; earns CTO only for punches inside authorized windows.
  • Monthly gate: Monthly DTR Submissions where plantilla review/submit is required.

E. Data produced for payroll

  • work_hours — one row per employee per calendar day in the quincena (gross, late, undertime, absence, net, remarks, year/month/quincena).
  • DtrQuincenaWorktimeSummary — quincena-level totals used by Worktime Summary and payroll screens.
  • Related ledgers (side effects): leave_ledger (VL/SL/CTO), jo_cos_overtime (X-Service OT).

F. Menu path (system)

  • Time & Attendance → Daily Time Records: Upload DTR Log, Edit remarks, Justifications, Flexible Worktime, X-Service Authorization
  • Processing: Quincena Processing, Monthly DTR Submissions, Prepare DTR Period, Process Worktime
  • Authorizations: Overtime Authorization (Plantilla)
  • Payroll → Processing: Worktime Summary, JO/COS, Plantilla
  • Payroll → Deductions: GSIS, HDMF, PHIC, LBP, JOFEMCO, Withholding Tax

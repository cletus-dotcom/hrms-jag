Quick start

  1. Log in using your assigned Employee ID and password.
  2. Check your dashboard for shortcuts and status counts.
  3. Do your task (apply leave, upload DTR, manage employees, etc.).
  4. Log out when you’re done—especially on shared computers.

DTR-to-payroll workflow

Time and attendance moves through clear phases each quincena. HR tracks status on Time & Attendance → Quincena Processing.

  1. Prepare DTR period (HR/Admin) — Generate blank rows for all employees in the quincena, plus holidays and workweek segments. Set flexible worktime, overtime authorization, and X-Service authorization.
  2. Upload DTR log (HR/Admin/DTR Uploader) — Upload the biometric .dat file for the quincena. Employees are notified to review their DTR.
  3. Employee review — Employees open My DTR, check late/undertime/absence flags, submit justifications, and may print their DTR.
  4. HR review & adjustment — HR closes employee review, approves or rejects justifications, and uses Adjust DTR to correct times or remarks.
  5. Process worktime (HR/Admin) — Recomputes late, undertime, absences, worktime summaries, leave ledger entries, and JO/COS overtime credits.
  6. Payroll (HR/Admin) — Worktime Summary, deductions, JO/COS or Plantilla payroll, and payslips for employee self-service.

Quincena statuses: Draft → Review open → Review closed → Processed. After a quincena is Processed, DTR rows are locked until HR reopens the period from Quincena Processing.

Guides by role

Sections marked Your role match your current account.

Admin & HR{% if viewer_role in ('admin', 'hr') %}Your role{% endif %}

Sidebar access: eRMT (add/edit; Admin can delete), Settings, full Time & Attendance (Processing), Leave Credits, Payroll, Reports (Employees List, Service Records, Leave Credits, Employee ID Cards), Notifications.

Typical quincena duties:

  1. Open Quincena Processing and confirm setup checklist (prepare period, authorizations).
  2. Use Prepare DTR Period to create blank rows and set workweek segments and holidays for the quincena.
  3. Upload DTR log or verify uploader completed upload.
  4. Monitor pending justifications; approve or reject with supporting review.
  5. Track plantilla Monthly DTR Submissions after the 2nd quincena upload.
  6. Close employee review when the deadline passes.
  7. Use View DTR Records → Adjust DTR to correct employee rows.
  8. Run Process Worktime, then review Worktime Summary and proceed to JO/COS or Plantilla payroll.

Also:

  • Employees: Add/edit employees and PDS; link ID Photo (eRMT) on the employee form; open Service Record or Print ID from the list/form.
  • Leave credits: Maintain ledger under Leave → Leave Credits; export Leave Credits PDF from the card or Reports → Leave Credits.
  • Reports: Reports → Service Records, Leave Credits, and Employee ID Cards; Employees List export (CSV/Excel/PDF).
  • Payroll: Upload/manage deductions, load JO/COS and Plantilla payroll, generate payslips for employee self-service.
  • eRMT: Encode records with cabinet/shelf and Network PDF path (NAS) (including type ID Photo); see eRMT and ID Cards.
  • Admin only: Delete eRMT records (DB entry only; NAS file is kept). Portal Console when signed in as portal admin.

Manager{% if viewer_role == 'manager' %}Your role{% endif %}

Sidebar access: Dashboard, eRMT (view/search), DTR records (department scope), leave apply/view, leave approvals, overtime offset approvals, My Records (if linked), Notifications.

  • Leave: Approve or reject leave for staff in your department via Leave → Leave Approvals.
  • DTR: View DTR for employees in your managed department(s). You cannot upload logs or process worktime.
  • Overtime offset: Review JO/COS overtime offset requests when assigned.
  • Self-service: Apply leave, review your own DTR/justifications if linked, view My PDS / Service Record / Payslips.
  • eRMT: Search and open NAS PDF links; you cannot add or edit records.

Employee{% if viewer_role == 'employee' %}Your role{% endif %}

Sidebar access: Dashboard, eRMT (view/search), My DTR, Leave self-service, My PDS, My Service Record, My Payslips, Notifications.

When DTR is uploaded for your quincena:

  1. Open Time & Attendance → My DTR (you receive a notification).
  2. Review each day for Late, Undertime, or Absent flags.
  3. Click Justify this day on a flagged row before the review deadline; attach proof when available.
  4. Use Print DTR to download a PDF copy (includes justification status).
  5. HR may still adjust your record before worktime is processed; check Notifications for updates.

Plantilla — monthly submission: After the 2nd quincena upload, open My DTR → Month (monthly submission), justify remaining flagged days, Print monthly DTR, then Submit monthly DTR before the deadline (default: 5th of the following month).

  • Leave: Leave → Apply for Leave; track under View Leave.
  • My Records: My PDS, My Service Record (appointment history), My Payslips (JO/COS or Plantilla). Dashboard shows your ID photo when HR has linked one.
  • JO/COS: Overtime Credits when applicable.
  • eRMT: Search records; use Copy path or try browser open for NAS PDFs (open via File Explorer / Adobe if the browser blocks file://).

DTR Uploader{% if viewer_role == 'dtr_uploader' %}Your role{% endif %}

Sidebar access: Dashboard, eRMT (view), View DTR Records, Upload DTR Log, Leave self-service, My Records (if linked), Notifications.

Primary task: Upload biometric attendance files for the correct quincena.

  1. Confirm with HR which quincena and file to upload.
  2. Open Time & Attendance → Upload DTR Log.
  3. Select the quincena, choose the .dat file, and click Upload and Save.
  4. Review the summary (records saved, dates outside quincena skipped, missing days).
  5. If you uploaded the wrong file, use Undo upload on your own recent batch (Admin/HR can undo any batch).

You can view DTR records and use self-service leave/DTR if your account is linked to an employee. You cannot process worktime or run payroll.

Payroll Maker{% if viewer_role == 'payroll_maker' %}Your role{% endif %}

  • DTR records: View attendance for active employees in your department.
  • Justifications: Review submissions; use Forward to send to HR/Admin for approve/reject.
  • Reports: Reports → Employees List (CSV, Excel, or PDF). Service Records, Leave Credits, and Employee ID Cards are Admin/HR only.
  • eRMT: View/search only.

Payroll load and Process Worktime are performed by HR/Admin after employee review is closed.

Common tasks (step-by-step)

A) Change your password

  1. Click your name at the top-right.
  2. Select Change password.
  3. Enter your current password and your new password.
  4. Click Change password.

B) Add a new employee (Admin/HR)

  1. Go to Employee Management → Employees.
  2. Click + Add Employee.
  3. The Employee ID is automatically generated. Fill in the rest of the form.
  4. Click Add Employee.

Note: If you see a duplicate/invalid ID, refresh the page and try again.

C) Open and update an employee PDS

  1. Open Employees list.
  2. Click an employee row to open the PDS.
  3. Update fields as needed and save.

D) Apply for leave

  1. Open Leave Management → Apply for Leave.
  2. Select the leave type and dates.
  3. Add details (reason, where required).
  4. Submit your application.
  5. Check status in Leave Management → View Leave.

E) Approve leave (Manager/Admin)

  1. Open Leave Management → Leave Approvals.
  2. Review the request details carefully.
  3. Approve or reject (when available).

F) Prepare DTR period (Admin/HR)

Run this before uploading the biometric log. It creates blank DTR rows for the selected period and can stamp rest days, holidays, and work suspensions. It does not fill 8:00/5:00 or 7:00/6:00 present-day times — plantilla and JO/COS keep actual biometric punches only.

  1. Open Time & Attendance → Prepare DTR Period (also available from Quincena Processing).
  2. Select Quincena (1st or 2nd half), Month, and Year. Preparation always covers all active employees for that quincena (plantilla and non-plantilla).
  3. Compressed workweek segments (optional) — use when the duty scheme is 4-day or 5-day compressed, or when it changes within the same quincena:
    1. Click Add workweek segment for each date range.
    2. Per segment, set Model (5-day or 4-day), Applies To (all employees, plantilla only, or non-plantilla only), and Start / End dates.
    3. Example: Segment 1 — 5-day, all employees, May 1–7; Segment 2 — 4-day, all employees, May 8–15.
    4. Each segment must fall entirely within the selected period. Segments that overlap for the same employee group are not allowed (e.g. two “all employees” ranges on the same dates). Different groups may overlap (e.g. plantilla 5-day and non-plantilla 4-day on the same dates).
    5. Leave segments empty if you only need blank rows (no REST DAY overlay).
  4. What each model does (excluding holidays and work suspensions):
    • 5-day compressed — used for late/undertime targets (8:00 AM / 12:00 PM / 1:00 PM / 5:00 PM). DTR In/Out stay blank until biometric upload.
    • 4-day compressed — late/undertime targets Monday–Thursday (7:00 AM / 12:00 PM / 1:00 PM / 6:00 PM); Friday marked REST DAY. No default 7:00/6:00 times on the DTR row.
    • Employees on the Flexible Worktime list (or the employee flexi flag) skip the 4-day Friday REST DAY overlay; that day’s flexi row (including Rest mode) owns the schedule. Rest mode can take several dates in the same quincena (click each rest day, then Add) — they do not need to be consecutive.
  5. Holidays / work suspension — pick dates on the calendar (full day, AM, or PM) or type one date per line (YYYY-MM-DD, optional AM or PM). These apply org-wide for the listed days.
  6. Before generating, set Flexible Worktime, Overtime Authorization, and X-Service Authorization on the same Time & Attendance menu when required for the period.
  7. Click Generate. The system saves workweek settings for late/undertime lookup and creates or updates DTR rows for the quincena.

To print a full-month DTR for plantilla employees (monthly submission requirement), open View DTR Records, set View by to Month, and use Print monthly DTR. Day-to-day payroll and review still use the Quincena view.

G2) Monthly plantilla DTR submissions (Admin/HR)

  1. After the 2nd quincena DTR is uploaded and both quincenas are closed for employee review, open Time & Attendance → Monthly DTR Submissions.
  2. Select month, year, and optional department filter.
  3. Review employees who have Submitted monthly DTR; open their month view if needed.
  4. Accept complete packets or Return for resubmit with review notes.
  5. Default employee deadline is the 5th of the following month (plantilla employees are notified after Q2 upload and reminded near the deadline).

G) Upload DTR log (DTR Uploader, HR, or Admin)

  1. Open Time & Attendance → Upload DTR Log.
  2. Select the correct quincena.
  3. Choose the biometric .dat file and click Upload and Save.
  4. Read the summary: records saved, outside-quincena dates skipped, and any missing calendar days.
  5. Employees are notified to review My DTR. HR monitors progress on Quincena Processing.

H) Review and justify your DTR (Employee)

  1. Open Time & Attendance → My DTR for the quincena.
  2. On a flagged day, click Justify this day (or open DTR Justifications).
  3. Enter a clear reason and attach supporting document if available.
  4. Submit before the review deadline shown on the page.
  5. Optionally click Print DTR to save a PDF copy.

I) Process a quincena (Admin/HR)

  1. Open Time & Attendance → Quincena Processing and select the quincena.
  2. Complete the setup checklist (prepare period, flexi, authorizations, upload).
  3. When employees finish reviewing, click Close employee review.
  4. Approve/reject justifications and Adjust DTR as needed.
  5. Run Process Worktime, then open Worktime Summary before payroll.

J) View worktime summary (Admin/HR)

  1. Open Payroll → Worktime Summary.
  2. Select year, month, quincena, employee type, and optional department or employee filters.
  3. Click Apply to load the report.
  4. Use CSV or PDF export if needed.

K) Export Service Record PDF (Admin/HR)

  1. Open Reports → Service Records (or an employee’s form / list action Service Record).
  2. Select the employee and open the Service Record page.
  3. Click Export PDF for a printable appointment history (municipal header, no department/position columns in the table).

Employees with a linked account can view their own history under My Records → My Service Record (on-screen; PDF export is for Admin/HR).

L) Export Leave Credits PDF (Admin/HR)

  1. Open Leave → Leave Credits and open an employee card, or use Reports → Leave Credits.
  2. Review the ledger (VL, SL, SPL, WL, CTO, LWOP).
  3. Click Export PDF (landscape A4).

M) Run Plantilla or JO/COS payroll (Admin/HR)

  1. Confirm the quincena is Processed and Worktime Summary looks correct.
  2. Upload or refresh deduction schedules (GSIS, HDMF, PHIC, LBP, JOFEMCO, withholding tax) as needed.
  3. Open Payroll → Plantilla or Payroll → JO/COS, select department/period, and load payroll.
  4. Generate payslips so employees can open them under My Payslips.

N) Print Employee ID Cards (Admin/HR)

  1. Ensure each employee has an ID Photo linked (see Employee ID Cards & ID photo).
  2. Open Reports → Employee ID Cards (or click Print ID on an employee list/form row).
  3. Optional: filter by department, status, and ID format (All / JO/COS only / Plantilla only).
  4. Click Print ID on one row for a single PDF, or select several employees and click Print selected (batch PDF).

Template is chosen automatically from appointment status: Job Order / Contract of Service → JO/COS ID; other plantilla appointments → Plantilla ID. Department text prefers the department description.

eRMT (electronic records)

Overview → eRMT catalogs scanned HR documents. The app stores metadata and a Network PDF path (NAS) only—files are not uploaded to the application server.

Who can do what:

  • All signed-in users: Search/filter records; copy NAS path; try browser open.
  • Admin / HR: Add and edit records (record number like ERMT-YYMMDD-NN, type, title, keywords, cabinet, shelf, remarks, NAS path).
  • Admin: Delete a record from the database (the file on the NAS remains).

Record types: Memorandum, Office Order, Reports, Certificates, Contracts, Personnel Records, 201 File, 2316 File, ID Photo, Others.

Add or update a record (Admin/HR)

  1. Open Overview → eRMT and click + New Record (or Update on an existing row).
  2. Fill record date, type, title, keywords, cabinet/shelf, and remarks.
  3. Paste the Network PDF path (UNC on the office NAS \\192.168.20.3\hrmdo\..., e.g. \\192.168.20.3\hrmdo\ID PICTURES\PLANTILLA\40555.jpg, or a mapped drive path). For ID photos, use an image path (.jpg / .png / similar). Save.

Open a NAS PDF

  1. Expand a record and use Copy path, then open the file in File Explorer, Adobe Acrobat, or Edge.
  2. Optional: Try browser open — many browsers block file:// links from an http(s) site; use Copy path if that fails.
  3. Your PC must be on the office network with access to \\192.168.20.3\hrmdo.

Employee ID Cards & ID photo

Admin/HR can print official LGU Jagna ID cards. Photos are not uploaded into the app database— they are linked from an eRMT image file on the office NAS (same pattern as other eRMT records).

1) Encode the ID photo in eRMT (Admin/HR)

  1. Copy the employee’s ID photo into the NAS folder \\192.168.20.3\hrmdo\ID PICTURES\PLANTILLA or \\192.168.20.3\hrmdo\ID PICTURES\JO (JPG/PNG recommended).
  2. In Overview → eRMT, create a record with type ID Photo.
  3. Set the Network file path to the full UNC path (e.g. \\192.168.20.3\hrmdo\ID PICTURES\PLANTILLA\40555.jpg) and save. Note the record number (e.g. ERMT-YYMMDD-NN).

2) Link the photo to the employee (Admin/HR)

  1. Open Settings → Employees and edit the employee.
  2. In ID Photo (eRMT), enter the eRMT record number and save.
  3. A preview appears when the path is readable from the app server. The same photo can show on the dashboard welcome card.

3) Print Plantilla or JO/COS ID cards (Admin/HR)

  1. Open Reports → Employee ID Cards.
  2. Filter by department, employment status, and ID format if needed.
  3. Use Print ID for one employee, or select multiple rows and Print selected (batch PDF).
  4. You can also print from the employee list/form via the Print ID action.

What appears on the card:

  • Plantilla: Official plantilla template; photo (~3.5 × 4.5 cm) with gold frame; name as FIRSTNAME M.I. LASTNAME, department description, and ID NO box on the lower left; QR code of the employee ID on the lower right.
  • JO/COS: JO/COS template (auto-selected for Job Order / Contract of Service); photo in the template slot; condensed name, department description, and ID NO box on the lower left; QR code of the employee ID on the lower right.

If the photo is missing, the card still prints with an empty photo area—link a valid eRMT ID Photo first for a complete card.

Best practices

  • Follow the quincena workflow: Do not run payroll until worktime is processed for that quincena.
  • Close employee review before adjusting DTR and processing worktime.
  • Be consistent: Use complete names and correct departments to keep reports accurate.
  • Double-check dates: Leave and DTR are date-sensitive; wrong dates cause payroll issues. Workweek segment dates must match the quincena or month you are preparing.
  • Attach proof when needed: Justifications are faster to review with supporting files.
  • eRMT paths: Prefer stable UNC paths on the shared NAS; avoid personal desktop folders.
  • ID photos: Use a clear front-facing photo; keep the eRMT path pointing at the current file after NAS folder moves.
  • ID card print: Filter by Plantilla vs JO/COS when batch-printing so you load the correct paper/stock.
  • Use search: Most lists support searching—use it instead of scrolling.
  • Log out: Always log out after using the system on shared devices.

Troubleshooting

Login problems

  • “Invalid credentials”: Check your Employee ID and password. Make sure Caps Lock is off.
  • Forgot password: Ask Admin/HR to reset your account password.
  • Stuck on login: Refresh the page. If it persists, restart the browser and try again.

Pages not showing / missing menus

  • Your role may not have permission for that page. Confirm your role with Admin/HR.
  • Try logging out and logging back in after role changes.
  • Service Records / Leave Credits / Employee ID Cards under Reports, Payroll menu, and eRMT edit/delete require Admin or HR (delete = Admin).

Prepare DTR / workweek segment issues

  • Overlapping segments: Two segments for the same employee group cannot cover the same dates. Split or adjust ranges, or use different Applies To values when plantilla and non-plantilla follow different schemes.
  • Dates outside the period: Start and end dates must fall within the selected quincena or month. Change the period or shorten the segment.
  • Wrong late/undertime targets: The system uses the workweek segment active on each calendar day. Re-run Prepare DTR Period with corrected segments before upload if you prepared the wrong scheme.
  • No default times stamped: Workweek segments are optional. Add at least one segment, or adjust DTR manually after upload.

DTR upload issues

  • Wrong quincena: Select the correct quincena before uploading. Dates outside the quincena are skipped automatically.
  • Incomplete quincena in file: Missing calendar days are listed in the upload summary; you can upload another file or let HR adjust.
  • Employee ID not found: Ensure the employee exists and the ID in the file matches the employee record.
  • Duplicate upload: New uploads merge with existing rows for the same day. Use Undo upload on the batch if the entire upload was wrong.
  • Cannot adjust DTR: If the quincena is Processed, HR must Reopen for adjustment on Quincena Processing first.

DTR justification issues

  • Cannot submit justification: The employee review window may be closed or past the deadline. Contact HR.
  • Flag still showing after justification: Justifications are documentation; HR must approve and may still adjust DTR times before worktime is processed.
  • Payroll Maker: Use Forward to send justifications to HR; only HR/Admin can approve or reject.

eRMT / NAS PDF issues

  • Browser won’t open the PDF: Copy the path and open it in File Explorer or Adobe. Browsers often block local/network file:// links from web apps.
  • Access denied / path not found: Confirm you are on the office network and can open \\192.168.20.3\hrmdo in File Explorer; ask IT if the share moved. The app server must also be able to read that path for ID photo previews/cards.
  • Cannot add/edit: Only Admin/HR can encode records. Only Admin can delete.

ID photo / ID card issues

  • No photo on card or dashboard: Link an eRMT record (type ID Photo) on the employee form; confirm the NAS image path exists and the app server can read it.
  • Works on dev PC but not on server (hrms.exe): The server process must log in to the NAS share. Either place a .env file in the same folder as hrms.exe, or set Windows environment variables before starting HRMS: ERMT_NAS_ROOT=\\192.168.20.3\hrmdo, ERMT_NAS_USER=hrmdo, ERMT_NAS_PASSWORD=… (share password). Restart hrms.exe and check the console for NAS connected.
  • Wrong template (Plantilla vs JO/COS): Check the employee’s appointment / employment status. JO and Contract of Service use the JO/COS template; other plantilla statuses use the Plantilla template.
  • Blank or incomplete name/department: Complete the employee name fields and department description (falls back to department name).
  • Batch print empty: Select at least one visible row after filtering; “Select all visible” only covers the current filtered list.

Leave printing / export issues

  • Some print/export options may only work when a leave request is Approved.
  • If PDF export looks clipped, try browser print settings: set paper to A4 and margins to “Default”.
  • Leave Credits PDF is Admin/HR only (landscape).

If something looks wrong

  • Refresh the page first (sometimes data updates after saving).
  • Check if you’re on the correct page/menu.
  • If the error message mentions “database” or “constraint”, contact Admin/HR and include a screenshot of the message.
